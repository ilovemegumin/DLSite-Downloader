最初にPython 3.11.xが入っていることを確認してください
py --versionで確認できます dev環境はPython 3.11.9でやりました
https://www.python.org/downloads/release/python-3119/
ダウンロードはこちら

確認できたらsetup.batをクリックして依存関係のインストールをしてください。中身が気になる場合は編集をして見てください
次は*.pyファイルがあるこのフォルダの名前が書いてあるところが上にあると思うので、
そこをクリックして何かが書いてあったら消してからcmdと入力してください。
ターミナルかコマンドプロンプトが開いたら、py main.pyと書いて実行してください。
そしたら起動は終わりです
あとはログインをしたら使えます

実行はFor_Lazy.batでも実行できます

Note
Beta版を使いたい場合やうまくできない場合は --betaを追加して起動してください。 ダウンロードAPIとマルチコネクションが使えるようになります。

オリジナルファイルを取得する場合は --original を追加してください。
--beta も互換エイリアスとして同じ動作をします。
例: py main.py --original --yes download RJ123456
オリジナルZIPを取得できない場合はエラーになります。-originalを外して試してください
